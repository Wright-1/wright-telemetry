# Wright Telemetry Collector

## Product Purpose

A local agent that runs on a customer's network, discovers mining hardware (ASICs), collects performance telemetry (temperature, hashrate, uptime, errors), and streams it to the Wright One cloud dashboard. The GUI simplifies the setup wizard that was previously terminal-only.

## Users

- **Mining facility operators**: technical enough to manage network hardware, but not comfortable with CLI wizards. They want a quick, trustworthy setup flow that gets the agent running without reading docs.
- **Wright One support staff**: occasionally walk customers through setup remotely via screen-share. A visual GUI is far easier to guide someone through than a TUI.

product

## Brand

Wright One. Industrial mining infrastructure company. Serious, transparent, no-nonsense. The brand says: "we run on your hardware, you should trust us."

## Tone

Direct, concise, trustworthy. No marketing fluff in the agent UI. Every label earns its place. Security and privacy are first-class concerns surfaced in the UI, not hidden in docs.

## Anti-references

- Electron apps with gratuitous animations and loading spinners
- Dark-mode-for-cool dashboards (this is a setup wizard, not a monitoring tool)
- Overly minimal "design system showcase" UIs that hide functionality
- SaaS onboarding flows with confetti and gamification

## Strategic Principles

1. **Transparency first**: every permission explains exactly what data is collected and why.
2. **Get out of the way**: the GUI exists to replace a TUI wizard. It should be faster, not slower.
3. **Trust through clarity**: security profile is always visible. Open source link is prominent.
4. **Three screens, done**: Permissions → Discovery → Overview. No more.
