Installing Wright Telemetry

macOS installation guide  ·  v0.7.3

🔒
Why does macOS block it?

Apple requires all distributed software to be signed and notarised through their Developer Program ($99/year). Wright Telemetry is free, open-source software. The app itself is safe — macOS is just letting you know it hasn't paid Apple's fee. The steps below let you approve it yourself in about 30 seconds.

Installation steps
1
Open this DMG and drag the app to Applications
Drag Wright Telemetry.app onto the Applications shortcut inside this window. Wait for the copy to finish before continuing.
📂 Wright Telemetry.app  →  Applications /
2
Right-click the app and choose Open
In Finder → Applications, find Wright Telemetry. Do not double-click yet. Instead, right-click (or Control-click) the icon and select Open from the menu that appears.
🖱️ Right-click → Open
3
Click "Open" in the security dialog
macOS will show a warning that says "Wright Telemetry can't be opened because it is from an unidentified developer." Click the Open button in that dialog to approve the app. This is a one-time step — after this, you can double-click it normally.
⚠️ Security dialog → click Open
If the dialog didn't appear
⚙️ System Settings  EASIEST
If macOS blocked the app without giving you an Open option, open Apple menu → System Settings → Privacy & Security. Scroll down to the Security section and you'll see:
🛡️ "Wright Telemetry was blocked from use because it is not from an identified developer."  →  Open Anyway
Click Open Anyway, enter your Mac password when prompted, then launch the app.
💻 Terminal (one command)  ADVANCED
Open Terminal (search Spotlight: ⌘ Space → type Terminal) and run:
$ xattr -dr com.apple.quarantine "/Applications/Wright Telemetry.app"
This strips the quarantine flag that macOS adds to downloaded files. The app will open normally from then on.
Why Wright Telemetry is safe to run
📖
Fully open source
Every line of code is public on GitHub. You can read, build, and verify it yourself before running anything.
🔑
No password exfiltration
Miner credentials are stored locally, encrypted with AES-256-GCM. They never leave your machine.
👁️
Read-only access
The agent reads miner metrics only. It cannot change firmware settings, reboot rigs, or issue any write commands.
✅
Your data, your choice
Every metric is off by default. The setup wizard explains each one before you enable it. Change your mind at any time.
⚠️
macOS Ventura (13) and later

On macOS 13+, Apple moved the Open Anyway button to System Settings → Privacy & Security. The right-click → Open trick also still works on all versions.
